# 算法岗三端刷题软件 (LeetCode 官方风格 · 739+ 题库)

> 基于《算法岗笔试题目大全.md》、《补充篇.md》与《选择题大全_含答案解析.md》深度构建，涵盖 **739+ 道** 2025-2026 校招与社招算法岗核心高频题库。
> 采用**力扣（LeetCode）官方客户端风格**，并针对**选择题**与**编程算法题**实现了专门的**独立差异化布局**！

---

## 一、界面样式完全分离（选择题 vs 算法题）

根据笔试与面试的真实交互场景，软件将**选择题**与**编程算法题**的做题页面彻底分离：

### 1. 🎯 笔试选择题专属答题卡模式（Choice Exam Workbench）
- **专为 143 道选择题深度定制，完全移除冗余的代码编辑器**！
- **A / B / C / D 专属大选项卡片**：
  - 支持鼠标点击作答，亦支持键盘直接按 `A`、`B`、`C`、`D` 快速选答案！
  - **即时对错反馈**：选对立即绿色高亮与对勾，选错红色抖动并高亮正确答案。
  - **即时权威解析**：答完后立即展开官方深度解析与知识点衍生，错题自动加入【错题本】。
- **右侧专属【选择题答题卡面板】**：
  - 1-143 题可视化矩阵答题卡（绿色=做对、红色=做错、灰色=未做、蓝色高亮=当前题目）。
  - 支持“全部 / 错题本 / 未作答”过滤，点击任意题号瞬间直达。
  - 实时统计做题进度、正确率与错题数。

### 2. 💻 力扣算法编程 IDE 模式（LeetCode Algorithm Workbench）
- **专为 LeetCode 编程与手撕算子定制的双栏 IDE**：
  - **左栏**：题目描述、输入输出示例、数据约束条件、官方题解、复杂度分析、提交历史与笔记。
  - **右栏**：Monaco / VS Code 风格代码编辑器（带行号、4 空格 Tab 缩进、Python3/PyTorch/SQL/C++ 语言切换）。
  - **底部控制台**：Case 1 / Case 2 测试用例面板、执行结果输出。
  - **“运行代码”与“提交”**：点击提交弹出官方同款 **通过 (Accepted)** 成绩卡（展示执行用时、内存消耗与击败率）及礼花动效！

## 二、三端快速启动方式

在当前文件夹下，直接双击对应的启动脚本即可：

| 终端形态 | 启动脚本 | 体验说明 |
|---|---|---|
| **🖥️ PC 网页端** | `启动-网页端.bat` | 自动打开默认浏览器访问 `http://localhost:5173` |
| **💻 PC 桌面独立客户端** | `启动-桌面客户端.bat` | 唤起独立 Electron 桌面应用窗口，无浏览器边框干扰 |
| **📱 手机移动端 PWA** | `启动-手机移动端局域网.bat` | 手机同 Wi-Fi 访问输出的 IP 地址，可“添加到主屏幕”作为独立原生 App 离线刷题 |

---

## 三、快捷键操作指南

- **选择题快速作答**：键盘直接按 `A`、`B`、`C`、`D` 即可立即选择对应选项
- **题目快速切换**：`J` 或 `←` 上一题，`K` 或 `→` 下一题
- **随机抽题**：按 `R` 键随机抽取题目
- **代码编辑器**：按 `Tab` 键自动缩进 4 个空格
